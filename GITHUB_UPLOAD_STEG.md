# GitHub-uppladdning

1. Ga till https://github.com/new
2. Skapa ett repository, till exempel `scrambled-site`.
3. Valj `uploading an existing file`.
4. Dra in filerna och mappen `assets` fran den har mappen.
5. Klicka `Commit changes`.
6. Ga till https://vercel.com/new och importera ditt GitHub-repository.

Vercel-installningar for projektet:

- Framework Preset: Other
- Build Command: tomt
- Output Directory: tomt eller `.`

Filer som ska upp till GitHub:

- `index.html`
- `styles.css`
- `script.js`
- `vercel.json`
- `.gitignore`
- `README.md`
- `assets/`
