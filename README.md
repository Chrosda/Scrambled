# Scrambled website

Statisk webbplats for Scrambled - AI, Product & Growth.

## Oppna lokalt

Oppna `index.html` direkt i webblasaren.

## Att uppdatera

- Kontaktmail finns pa tre stallen i `index.html`: sok efter `hello@scrambled.se`.
- LinkedIn-lanken finns i kontaktsektionen i `index.html`.
- Farger och spacing finns i `styles.css` under `:root`.
- Hero-illustration och ikon ligger i `assets/`.
